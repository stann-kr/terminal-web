# TERMINAL 디자인 시스템

낮은 채도의 아이스블루와 청회색 바탕, 인쇄물 같은 좌우 rail과 가는 구획선으로 행사·사람·기록을 정리합니다.

- 바탕 `#080e13`, 표면 `#0d171e`, 주요 색 `#afcbdc`, 본문 `#d5e6ef`, 보조 텍스트 `#8ea6b5`, 구획선 `#405763`.
- Space Mono는 정보·숫자, Syncopate는 브랜드·표제, Orbit은 한국어를 담당합니다. 로컬 font 자산을 사용합니다.
- 본문 14px, 긴 소개 13px, 입력 16px, 메타 10~12px. 주요 control 최소 44px, 숫자는 필요한 곳에 tabular.
- 홈은 요약/대표 행사/로그, 이벤트는 선택/상세/행동, 아티스트는 명부 셀, 프로필은 신상/출연/소개, 기록은 행사 카드/집계, 방명록은 작성/공개 글의 고유 구성을 가집니다.
- 페이지당 기록 4개, 아티스트 12개, 공개 글 5개로 정보량을 제한합니다. 긴 원문은 native details로 열 수 있습니다. 동의·오류·주 행동은 생략하지 않습니다.
- 작은 화면은 의미 순서로 재배치하고 문서 스크롤을 허용합니다. 화면 높이에 맞추기 위해 글자를 축소하거나 내용 전체를 숨기지 않습니다.
- 포커스는 2px 아이스블루 외곽선. selected와 hover, pending, empty, error, saved를 구별합니다. reduced-motion 규칙을 유지합니다.
- 홈 도형·회전·가짜 실시간 그래프는 사용하지 않습니다. 경고색은 실제 실패 상태에만 씁니다.
