# TERMINAL 디자인 시스템

우주선 내부 장비 화면처럼 슬레이트 네이비 바탕에 민트 선과 평면 색 plate로 행사·사람·기록을 정리하는 인터페이스입니다. 미래감은 발광·주사선 같은 효과가 아니라 정돈된 격자, 균일한 선, 색 분류, 깎인 모서리와 해칭에서 나옵니다. 하드웨어 베젤·물리 버튼은 쓰지 않고 화면 안의 문법만 사용합니다.

## 색

- 바탕 `#0d1b24`, 패널 `#142631`, 입력 우물 `#09141b`, 본문 `#deece7`, 보조 `#aac7c0`, 흐린 글자 `#84a5a0`, 선 `#3b5963`, 약한 선 `#223a45`, 창 테두리 `#5d8790`.
- 주 선·강조는 민트 `#bfe6da`입니다. plate 색은 의미로만 씁니다: 샌드 `#dcc49a` = 예정 행사·대표 기록, 틸 `#6fd0cc` = 진행 중, 민트 = 지난 기록·주 행동, 주황 `#e8874f` = STANN LUMO와 포커스·스크롤 위치 표시, 슬레이트 `#4f6b73` = 장식 plate. 경고색 `#f07a7a`는 실제 실패에만 씁니다.
- `data-surface="sand|mint|teal|signal|slate"`를 붙인 요소 안에서는 같은 토큰이 반전되어 글자·선·버튼·셀이 plate 위에서 읽히도록 바뀝니다. 모든 조합은 본문 대비 4.5:1 이상입니다(흐린 선 `#3b5963`은 장식 선 전용).

## 글꼴과 크기

- 표제·라벨·버튼은 `Barlow Condensed`(대문자, 넓은 자간), 본문은 `Barlow`, 숫자·코드·콘솔은 `Share Tech Mono`입니다. 모두 OFL이고 Latin 서브셋 woff2(`public/fonts/instrument/`)입니다. 한글은 D2Coding 1.3.2 KS X 1001 서브셋을 한글 `unicode-range`에만 적용합니다.
- 크기는 메타 12px, UI 14px, 본문 16px, 리드 22px, 제목 30px, 표시 `clamp(40px, 5.2vw, 84px)`입니다. 입력은 16px 이상입니다.

## 화면 구조

- 전체 폭을 쓰는 벽면입니다. 상단 바(민트 브랜드 plate · F1–F4 키 · UNIT·KST 시계·KO/EN), 상태줄(샌드 구역 코드 plate `01 HOME` · 경로 · 눈금자 · 셀 스캐너 · 조회 램프), 점 격자 작업면, 명령 콘솔, 키 안내 줄의 다섯 줄입니다.
- 작업면의 페이지는 높이를 끝까지 채웁니다. 열은 늘어나고, 콘텐츠가 끝난 자리는 단색 plate(시스템 이름과 코드), 해칭 칸, 빈 등록 타일(`---- 0000`)로 메웁니다. 장식 plate는 링크가 아니며 접근성 트리에서 제외합니다.
- 패널은 오른쪽 위 모서리를 깎은 색조 면이고, 표제는 큰 콘덴스드 글자와 2px 선, 오른쪽 코드 칸입니다. 주 행동·현재 탭·섹션 plate는 오른쪽 아래 모서리를 깎습니다.
- 홈은 기록 지표 / 대표 행사 plate(상태 색) / 최근 방문자 로그·plate의 세 열입니다. 이벤트 목록은 줄 친 등록부와 요약 열, 행사 상세는 상태 색 개요 plate / 무대별 공연표 / 소개·참여 안내입니다. 아티스트는 3단 코드 타일(`ARTIST / 국가` · 스텐실 · 이름 · 일련번호) 격자이며 예정 출연은 샌드, STANN LUMO는 주황 plate입니다.
- 카운트다운은 두 줄 테두리의 숫자 칸 네 개와 해칭된 단위 줄입니다. 사실 표는 짧은 모노 라벨과 오른쪽 값의 줄 친 행입니다.

## 장식의 원칙

- 쓰는 것: 사각 셀(`Blocks`), 눈금자(`Ticks`), 해칭, ⊠ 교차 박스, 단색 plate, 코드·일련번호 텍스트. 상식적인 선의 장식 코드 밀도는 허용합니다.
- 쓰지 않는 것: 가짜 그래프·오실로스코프·레이더 같은 복잡한 계기 SVG, 바코드, 발광·주사선·노이즈·플리커, 글리프 해독.
- 실제 값에 묶는 곳: 상태 분포 셀, 방문자 메시지 길이 게이지, 조회·전송 상태(샌드 스캔·램프), 스크롤 위치 표식, 행사 상태 색.

## 상호작용과 모션

- 호버·포커스는 행·타일 전체를 상태 색으로 반전합니다. 켜짐은 즉시, 꺼짐은 140ms입니다.
- 첫 방문은 탭 세션당 한 번 상태 plate 네 줄이 차례로 켜진 뒤 물러납니다. route 전환은 본문이 위에서부터 8단계로 켜집니다. 목록 행·타일은 순서대로 계단식 등장합니다.
- `prefers-reduced-motion`, 고대비, 데이터 절약, 숨겨진 탭에서 모션을 끕니다. 별도 효과 스위치는 두지 않습니다.

## 접근성

- 페이지 제목은 접근성 h1입니다. 주요 조작 최소 높이는 44px입니다.
- 포커스는 주황 2px 아웃라인이며, 깎인 모서리 요소와 채움 행은 안쪽 아웃라인을 씁니다. 고대비에서는 시스템 색을 씁니다.
- 장식 plate·셀·코드 텍스트는 `aria-hidden`이라 링크 이름과 읽기 순서를 바꾸지 않습니다.
