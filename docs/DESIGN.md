# TERMINAL 디자인 시스템

테크노 이벤트를 위한 힙노틱·퓨처리스틱 콘솔입니다. 짙은 남색 작업면에 남색 판을 맞물리고, 크림·골드·오렌지·레드 단색 판을 소수만 두어 대비를 크게 만듭니다. 판 안은 실제 데이터를 쪼갠 셀과 표로 빽빽하게 채우고, 동심원 링을 하나의 그래픽 모티프로 씁니다. 우주선 장비 UI는 구조 참고일 뿐이며 깎인 모서리·⊗ 표식·사선 해칭 같은 게임 UI 기호는 쓰지 않습니다. 터미널 은유, CRT 효과, 하드웨어 베젤, 슬로건 문구도 쓰지 않습니다.

## 색

- 팔레트: 크림 `#fce5cd`, 골드 `#fcbf49`, 오렌지 `#f77f00`, 레드 `#d62828`, 남색 `#003049`. 작업면 `#001a29`, 헤더·푸터 바 `#00121d`.
- 남색 판: 크림 글자(11.3:1), 흐린 글자 `#c9b8a6`, 표제·숫자는 골드(8.4:1), 셀은 크림 바탕에 남색 글자. 크림·골드 판: 남색 글자와 남색 셀. 오렌지 판: `#001a29` 글자(6.8:1). 레드 판: `#fff8f0` 글자(4.75:1)와 남색 셀. 레드는 남색 위 글자로 쓰지 않습니다.
- 상태: 예정은 골드 셀, 진행 중은 레드 판, 대표 행사는 오렌지 판, STANN LUMO는 오렌지 셀, 지난 기록은 크림.
- `data-surface="navy|deep|cream|gold|orange|red"`가 판 색과 역할 토큰(`--ink`, `--muted`, `--accent`, `--line`, `--fill`, `--on-fill`, `--well`, `--hi`, `--on-hi`)을 정합니다.
- 칸은 테두리로 구분하지 않습니다. 채운 칸(`--fill`)과 톤 칸(`--well`, 판 위에 글자색을 8–16% 얹은 칸)의 명도 차이로 나눕니다. 선은 판 표제선·구분선·덱의 강조 막대에만 씁니다. 체크박스만 조작 영역 식별을 위해 테두리를 둡니다.

## 글꼴과 크기

- "TERMINAL"이라는 단어는 어디서든 `ProcrastinatingPixie`(`public/fonts`)로 씁니다(`BrandText`). 헤더 로고도 이미지 없이 같은 글꼴의 텍스트 "TERMINAL"(오렌지, 호버 시 골드)입니다.
- 표제·라벨·버튼은 `Barlow Condensed` 600–800 대문자, 본문은 `Barlow`, 숫자·코드는 `Share Tech Mono`(OFL, Latin woff2). 한글은 시스템 산세리프입니다.
- 크기는 1280→1920px에 따라 커지는 7단계입니다: `--t-xs` 12–14px(칩·메타) · `--t-sm` 14–16 · `--t-md` 16–18(본문·값) · `--t-lg` 19–24(셀 이름·버튼) · `--t-xl` 26–38(판 표제·행 제목) · `--t-2xl` 36–60(카운터·큰 숫자) · `--t-3xl` 56–124(대표 세션명). 12px 미만 글자는 쓰지 않습니다. 여백 `--pad`와 간격 `--gap`도 화면 폭에 따라 커집니다.

## 화면 구조

- 셸: 짙은 헤더 바(오렌지 TERMINAL 텍스트 로고 · `01 HOME` 탭 · 조회 램프 · KST 시계 · KO/EN · 오렌지 링 블록, 오렌지 하단선), 판이 타일링되는 작업면, 레드 상단선의 푸터 바. 페이지 전체가 문서로 스크롤되며, 푸터는 내용이 짧으면 화면 바닥에, 길면 마지막 판 뒤에 옵니다. 판마다 따로 스크롤하는 영역은 두지 않습니다.
- 알림: 안내는 톤 칸, 조회 실패는 레드 판(`ERROR` 라벨 · 제목 · 설명, 오른쪽에 `다시 불러오기` 키)입니다.
- 판: 직각 판, 골드 영문 표제와 3px 표제선, 한글 제목, 오른쪽 칩. 안에는 소제목, 크림 라벨 칸/선 값 칸, 셀 격자, 칩, 분할 막대를 층층이 둡니다. 남는 높이는 가는 선과 짧은 이름만 둔 예비 칸(`Bay`)으로 비워 둡니다. 로고 모양 장식(열린 사각 프레임)은 쓰지 않습니다.
- 버튼은 화살표 없이, 판 아래(또는 판 바닥)에 붙는 별도 카드 `ActionDeck`(짙은 바탕, 오렌지 왼쪽 선, 골드 라벨)에 모읍니다. 기본 키는 톤 칸, 주 키는 골드 칸입니다.
- 동심원 링은 대표 행사 판과 헤더·푸터의 링 블록에만 쓰며, 모두 같은 박자(138 BPM, 한 마디 1.739초에 한 링)로 퍼집니다.
- 홈: NEXT SESSION 오렌지 판(뒤에서 링이 퍼지는 힙노틱 필드, 카운트다운, 일정, 라인업) / SESSION ARCHIVE / STATUS 골드 판 / ARTIST ROSTER / NODE ACTIVITY(최신순 NODE-XXXX만, 시각·닉네임·메시지 없음) / SIGNAL 레드 판.
- 목록은 칸 행과 크림·골드 ID 셀, 상세는 SESSION(상태 색) · RUNNING ORDER · BRIEFING · ACCESS 판, 아티스트는 셀 격자와 집계 판입니다.

## 반응형

- 판·폼·셀은 `container-type: inline-size`라 브라우저 폭이 아니라 자기 폭에 반응합니다. 큰 제목(대표 세션명, 개요 제목, 프로필 이름, 셀 이름, 판 표제)은 `cqi` 단위로 판 폭에 맞춰 줄어듭니다.
- 좁은 판에서는 라벨/값 표가 세로로 쌓이고(440px 미만), 행사 행은 두 줄(780px 미만)·한 줄(480px 미만) 배치로, 공연표·출연 기록은 세로 배치(560px 미만)로 바뀝니다. 표 열은 subgrid로 내용 폭에 맞춥니다.
- 짧은 라벨·코드·시간·칩은 줄바꿈하지 않습니다. 전역 `overflow-wrap`은 `break-word`라 칸의 최소 폭을 줄이지 않습니다.
- 390·768·1024·1280·1440·1920px에서 8개 route의 잘림·의도치 않은 줄바꿈·가로 스크롤이 없음을 측정했습니다.

## 상호작용과 모션

- 호버는 카드나 키 전체가 판의 강조색(`--hi`)으로 켜지는 방식입니다. 채움은 포인터가 들어온 쪽에서 8분음표(217ms) 동안 쓸려 들어오고, 글자색은 채움이 반쯤 왔을 때 바뀝니다. 누르는 동안에는 백라이트 스위치처럼 반전됩니다. 남색·짙은 판은 골드, 크림·골드 판은 레드, 오렌지·레드 판은 크림입니다. 이미 골드인 칸은 크림으로 켜지고, 덱 안의 키는 크림으로 켜집니다. 위치는 움직이지 않고 테두리·밑선도 생기지 않습니다. 제목만 링크인 카드도 링크 영역을 카드 전체로 넓힙니다. 헤더·푸터 탭은 쉬는 상태가 톤 칸, 호버가 크림, 현재 위치가 골드입니다.
- 모션은 우주 정거장 콘솔을 손으로 조작하는 느낌을 목표로 합니다. 모든 길이와 지연은 138 BPM의 음표 값입니다: `--beat` 435ms · `--q8` 217ms · `--q16` 109ms · `--q32` 54ms. 곡선은 `--snap`(계기 이동)과 `--settle`(판독값 고정)입니다.
- 판 전원: 판이 화면에 들어오면 윗변에 밝은 선이 먼저 그어지고, 판 면이 그 선에서 아래로 열립니다(1박). 판끼리는 16분음표 간격, 판 안 칸(`data-cells`)은 32분음표 간격으로 켜집니다. 스크롤해서 들어오는 판도 같습니다.
- 명령 확인: 사이트 안 링크로 이동하면 누른 지점에서 오렌지·골드 링 세 겹이 16분음표 간격으로 퍼지고, 헤더·푸터 링 블록이 두 박 동안 골드로 빠르게 울립니다. 조준선·좌표 판독값 같은 장식은 쓰지 않습니다.
- 콘솔 포인터: 정밀 포인터(마우스·트랙패드)에서는 사이트 전용 커서를 씁니다. 포인터에 붙는 6px 점과, 16분음표 감쇠로 뒤따르는 30px 링입니다. 조작 요소 위에서는 링이 1.6배로 열리며 골드가 되고, 누르면 오므라듭니다. 입력칸 위에서는 시스템 텍스트 커서로 돌아갑니다. `difference` 합성이라 어느 판 위에서도 보입니다. 고대비에서는 끄고, 모션 줄이기에서는 지연 없이 따라갑니다.
- 부드러운 휠: 휠 입력은 목표 위치로 모이고, 페이지가 8분음표 감쇠로 미끄러져 따라갑니다. 키보드·스크롤바·터치·확대·가로 입력과 입력칸·안쪽 스크롤 영역의 휠은 기본 동작 그대로입니다.
- 공유 요소: 목록의 행사 행과 홈 대표 행사 판은 상세 SESSION 판으로, 아티스트 셀은 프로필 판으로 이어집니다(View Transition, 스냅샷은 늘이지 않고 창처럼 열림). 헤더의 골드 현재 탭은 다음 탭으로 미끄러져 옮겨 갑니다. 나머지 화면은 즉시 바뀌고, 도착은 판 전원이 맡습니다.
- 판독값(카운트다운·카운터)은 자리마다 창이 있어, 바뀐 숫자만 위에서 굴러 내려옵니다.
- 링은 박자에 맞춰 퍼지고, 푸터에는 실제 일정 데이터가 흐르는 티커가 있습니다(호버 시 멈춤). 조회·전송 중에는 램프가 깜빡입니다. 타자·스캔 출력과 게임 UI 기호는 쓰지 않습니다.
- `prefers-reduced-motion`, 고대비, 데이터 절약, 숨겨진 탭에서 모션을 끕니다. 판 전원은 스크립트가 켜지고 모션이 허용될 때만 판을 가리므로, 어느 경우에도 내용이 숨은 채로 남지 않습니다.

## 접근성

- 페이지 제목은 접근성 h1입니다. 영문 판 표제·코드·일련번호·예비 칸은 `aria-hidden`이라 heading과 링크 이름은 한글 제목과 실제 내용만 읽습니다.
- 주요 조작 최소 높이는 44px입니다. 포커스는 남색 위에서 골드, 밝은 판 위에서 짙은 색 2px 아웃라인이며, 채운 요소는 안쪽 아웃라인을 씁니다. 포커스 표시는 테두리 제거 대상이 아닙니다. 고대비에서는 톤 칸이 사라지므로 키·칸·입력에 시스템 색 테두리를 돌려줍니다.
