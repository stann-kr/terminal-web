# TERMINAL 디자인 시스템

우주선 내부 장비 화면처럼, 깊은 청록 네이비 위에 밝은 민트 선과 평면 패널로 행사·사람·기록을 정리합니다. 미니멀하고 정확한 선, 작은 콘덴스드 라벨, 절제된 큰 표제로 미래적인 인상을 만듭니다. 터미널(명령줄·커서·부팅 로그)과 CRT 효과, 하드웨어 베젤, 복잡한 가짜 계기 그래픽은 쓰지 않습니다.

## 색

- 바탕 `#10283a`, 패널 `#173447`, 입력 칸 `#0b1f2e`, 본문 `#e6fcf6`, 보조 `#b3dcd4`, 흐린 글자 `#86b9b1`, 선 `#46798a`, 약한 선 `#21465b`.
- 주 강조는 민트 `#c4f6ea`(라벨 탭·라벨 칸·주 행동·현재 메뉴)입니다. 상태에만 색을 더합니다: 시안 `#4fe3dc` = 진행 중, 샌드 `#f2d9a0` = 예정·다음 행사, 주황 `#ff8c4a` = STANN LUMO와 포커스. 경고색 `#ff7b7b`는 실제 실패에만 씁니다.
- 한 화면은 민트 계열 하나를 기본으로 하고, 색 plate(`data-surface="mint|cyan|sand|signal"`)는 의미 있는 한두 곳에만 둡니다. plate 안에서는 같은 토큰이 반전됩니다. 모든 글자 조합은 대비 4.5:1 이상입니다.

## 글꼴과 크기

- 라벨·표제·버튼은 `Barlow Condensed`(대문자, 넓은 자간), 본문은 `Barlow`, 숫자·코드는 `Share Tech Mono`입니다(OFL, Latin 서브셋 woff2, `public/fonts/instrument/`). 한글은 시스템 산세리프(Apple SD Gothic Neo, Noto Sans KR, Malgun Gothic)로 표시합니다.
- 크기: 라벨 12px, UI 14px, 본문 16px, 리드 20px, 제목 28px, 표시 `clamp(44px, 5vw, 80px)`. 입력은 16px 이상입니다.

## 화면 구조

- 셸: 상단 바(워드마크 · `01 HOME` 형식 주 메뉴 · 조회 램프 · KST 시계 · KO/EN), 점 격자 작업면, 하단 한 줄(SIGNAL·ABOUT·표기 기준). 작업면의 열은 화면 아래까지 늘어납니다.
- 패널: 1px 선 틀, 머리 줄 왼쪽에 민트 라벨 탭(영문, 오른쪽 아래 모서리 깎임)과 한글 제목, 오른쪽에 코드. 콘텐츠가 끝난 높이는 옅은 해칭 예비 칸(`Bay`)과 짧은 이름으로 채웁니다.
- 사실 표: 채운 라벨 칸과 선 값 칸의 짝. 목록: 칸으로 나뉜 행, ID 칸만 상태 색으로 채움. 공연표: 무대 라벨 탭 아래 코드·이름·시간 칸.
- 아티스트: 등록 타일(머리 줄 · 이름 · 기록 태그와 4자리 일련번호). 예정 출연은 샌드, STANN LUMO는 주황 plate. 마지막 줄은 빈 타일(`---- 0000`)로 채웁니다.
- 카운트다운: 민트 선 숫자 칸 네 개와 채운 단위 줄.

## 상호작용과 모션

- 호버는 테두리를 민트로, 행·타일에 옅은 채움을 더합니다(120ms). 주 행동은 채운 키, 나머지는 선 키입니다.
- 상태 모션은 실제 조회·전송 중일 때의 램프 점멸과 게이지 다음 칸뿐입니다. 부팅·전환 와이프·스캔·타자 출력은 없습니다.
- `prefers-reduced-motion`, 고대비, 데이터 절약, 숨겨진 탭에서 모션을 끕니다.

## 접근성

- 페이지 제목은 접근성 h1입니다. 영문 라벨 탭·코드·일련번호·예비 칸은 `aria-hidden`이라 heading과 링크 이름은 한글 제목과 실제 내용만 읽습니다.
- 주요 조작 최소 높이는 44px입니다. 포커스는 주황 2px 아웃라인이며, 채운 요소는 안쪽 아웃라인을 씁니다. 고대비에서는 시스템 색을 씁니다.
