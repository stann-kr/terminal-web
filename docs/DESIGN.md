# TERMINAL 디자인 시스템

우주선 내부 장비 화면(VESSEL VIEW·POWER GRID 같은 계통 패널)처럼, 슬레이트 바탕 위에 채도 낮은 밝은 판을 좁은 간격으로 맞물리고, 판 위를 짙은 잉크 글자와 짙은 코드 셀로 빽빽하게 채웁니다. 밀도는 가짜 계기 그래픽이 아니라 실제 데이터를 쪼갠 모듈(집계 행, 세션 셀, 명부 셀, 일정 칸, 상태 표)로 만듭니다. 터미널(명령줄·커서·부팅 로그), CRT 효과, 하드웨어 베젤은 쓰지 않습니다.

## 색

- 바탕 슬레이트 `#394f56`, 헤더·푸터 바 스틸 `#44666f`(작은 시안 `#9ff2f5` 제목만). 판 색: 세이지 `#9fbab4`, 페일 민트 `#b3d3cd`, 샌드 `#d9c29c`, 크림 `#e6e8d9`, 피치 `#f2c78f`. 판 위 잉크 `#243033`, 흐린 글자 `#2f4245`, 짙은 셀 `#3a4547`과 그 위 글자 `#e9efe6`.
- 상태 색: 예정·다음 세션은 샌드 판과 피치 셀, 진행 중은 피치 판, 지난 기록은 세이지. STANN LUMO는 주황 `#e0844e` 셀 하나. 경고는 실제 실패에만 씁니다.
- `data-surface="sage|mint|sand|cream|peach|signal|steel"`가 판 색과 역할 토큰(`--ink`, `--muted`, `--line`, `--fill`, `--on-fill`)을 정합니다. 모든 글자 조합은 대비 4.5:1 이상입니다.

## 글꼴과 크기

- 라벨·표제·버튼은 `Barlow Condensed` 600–800(대문자), 본문은 `Barlow`, 숫자·코드는 `Share Tech Mono`입니다(OFL, Latin 서브셋 woff2, `public/fonts/instrument/`). 한글은 시스템 산세리프(Apple SD Gothic Neo, Noto Sans KR, Malgun Gothic)로 표시합니다.
- 판 표제 28px 굵은 콘덴스드 대문자와 3px 잉크 밑줄, 소제목 15px, 본문 15px, 대표 세션명 `clamp(44px, 5vw, 84px)`. 입력은 16px 이상입니다.

## 화면 구조

- 셸: 스틸 헤더 바(워드마크 · `01 HOME` 탭 · ⊗ 표식 · 조회 램프 · KST 시계 · KO/EN · 해칭 SEOUL NODE 블록), 판이 타일링되는 작업면, 스틸 푸터 바.
- 판: 오른쪽 위 모서리를 깎은 평면 판, 큰 영문 표제와 한글 제목, 오른쪽 칩. 안에는 소제목(ALPHA CORES 형), 짙은 라벨 칸/선 값 칸(STR ALPHA · 122 형), 짙은 코드 셀 격자, 테두리 칩, 분할 막대를 층층이 둡니다. 남는 높이는 잉크 해칭 예비 칸(`Bay`)으로 채웁니다.
- 홈: NEXT SESSION 샌드 판(카운트다운 칸·일정·라인업 셀) / SESSION ARCHIVE(집계·세션 셀) / STATUS(D1–D3 상태 행) / ARTIST ROSTER(명부 셀) / TRANSMISSIONS(최근 로그) / SIGNAL 피치 판.
- 목록은 칸으로 나뉜 행과 짙은 ID 셀, 상세는 SESSION·RUNNING ORDER·BRIEFING·ACCESS 판, 아티스트는 짙은 모듈 셀과 REGISTER·ORIGIN 판입니다.

## 상호작용과 모션

- 호버는 셀을 밝히거나 옅은 잉크 채움을 더합니다(120ms). 주 행동은 짙은 채운 키, 나머지는 잉크 선 키입니다.
- 상태 모션은 실제 조회·전송 중일 때의 램프 점멸과 게이지 다음 칸뿐입니다. 부팅·전환 와이프·스캔·타자 출력은 없습니다.
- `prefers-reduced-motion`, 고대비, 데이터 절약, 숨겨진 탭에서 모션을 끕니다.

## 접근성

- 페이지 제목은 접근성 h1입니다. 영문 판 표제·코드·일련번호·예비 칸은 `aria-hidden`이라 heading과 링크 이름은 한글 제목과 실제 내용만 읽습니다.
- 주요 조작 최소 높이는 44px입니다. 포커스는 판 위에서 잉크, 스틸 바에서 주황 2px 아웃라인이며, 채운 요소는 안쪽 아웃라인을 씁니다. 고대비에서는 시스템 색을 씁니다.
