# TERMINAL 디자인 시스템

검정 화면 위의 1px 벡터 선과 인광 녹색 글자로 행사·사람·기록을 정리하는, 영화 속 우주선·시설 단말기(에일리언, 사일로) 같은 터미널 인터페이스입니다. 화면 틀·곡면 유리·하드웨어 키 같은 외부 물성은 쓰지 않고, 화면 안의 할레이션·주사선·계기 장식과 선의 위계로 몰입감을 만듭니다.

## 색

- 바탕 `#010502`, 주요 색 `#75e69a`, 본문 `#cbefd6`, 보조 텍스트 `#70ae85`, 구획선 `#367a4d`, 초점 창의 테두리 `#4f9e69`, 약한 구분선 `#183e24`.
- 앰버 `#e8b96b`는 예정·진행 중인 행사, 현재 입력 위치, STANN LUMO 강조에만 씁니다. 경고색 `#cd667b`는 실제 실패 상태에만 씁니다.
- 한 화면의 강조색은 녹색 하나를 기본으로 하고 앰버는 상태를 나타낼 때만 더합니다.

## 글꼴과 크기

- `'Space Mono', 'D2Coding', monospace`가 본문·정보·숫자를 맡고, `'Syncopate'`가 브랜드·행사명·섹션 표제를 맡습니다. 한글은 D2Coding 1.3.2 KS X 1001 서브셋(OFL)을 한글 `unicode-range`에만 적용해 고정폭 격자를 유지합니다.
- 크기는 다섯 단계입니다: 메타 11px, UI 13px, 본문 15px, 리드 20px, 표시 `clamp(28px, 3.6vw, 52px)`. 입력은 모바일에서 16px 이상입니다.
- 한글은 어절 단위로 줄을 바꿉니다(`keep-all`). 숫자는 필요한 곳에서 tabular입니다.

## 화면 구조

- 전체 화면은 상단 레일(브랜드·주 메뉴 탭 F1–F4·KST 시계·KO/EN), 상태줄(`guest@terminal:` 경로·눈금자·셀 스캐너·조회 상태), 본문, 명령 콘솔, 키 안내 바의 다섯 줄로 구성합니다. 넓은 화면에서는 왼쪽에 세로 인쇄 레일, 오른쪽에 본문 스크롤 위치를 따라가는 눈금자를 둡니다.
- 주 메뉴 탭은 1px 틀의 라벨이며 현재 위치만 녹색 단색 블록으로 반전합니다. 키 안내 바는 `F1–F4 화면 ··· / 명령줄 ··· ESC 출력 접기` 형식의 점선 리더와 보조 메뉴(SIGNAL·ABOUT)를 담습니다.
- 섹션 표제는 채운 띠가 아니라 사각 점·표제·틀 코드 태그와 그 아래 1px 선이며, 선의 시작에 밝은 등록 표식이 있습니다.
- 1px 틀의 창은 화면의 초점에만 씁니다: 홈 대표 행사, 행사 상세의 무대별 공연표, 신청·소식 폼, 공개 로그. 창의 머리 줄은 상태·역할·ID 칸으로 나누고, 필요하면 코드 칸 하나만 단색 블록으로 채웁니다. 박스 중첩은 한 단계까지입니다.
- 사실은 `라벨 ········ 값` 점선 리더로, 이벤트 목록은 열 머리가 있는 `ls -l` 형식의 행으로 보여 줍니다. 출연진은 행의 둘째 줄입니다.
- 카운트다운은 칸마다 1px 선으로 나눈 타임코드 한 줄이고, 단위는 숫자 아래에 표시합니다.
- 아티스트 명부는 머리 줄·스텐실 글리프·이름 줄로 이루어진 셀이며, 예정 출연과 STANN LUMO는 앰버로 구별합니다. 프로필은 신원 카드·출연 연대기·소개의 세 칸입니다.
- 작은 화면에서는 주 메뉴가 4칸 한 줄(44px)이 되고, 홈의 명령어 목록은 한 줄 안내로 접혀 대표 행사가 먼저 보입니다.

## 계기 장식

- 사각 셀(`Blocks`): 켜진 셀 하나가 격자를 스캔하며 인광처럼 감쇠하고, 지정한 셀이 어긋난 위상으로 깜빡입니다. 초 단위 스캔은 실제 초에 맞춰 한 칸씩 전진합니다.
- 눈금자(`Ticks`), 모서리 브래킷과 등록 십자(`Corners`), 인쇄 바코드(`Barcode`), 오실로스코프(`Scope`)를 화면별로 배치합니다. 모두 접근성 트리에서 제외합니다.
- 실제 값에 묶는 곳: 상태 분포(비율만큼 켜진 셀), 방문자 메시지 길이(28칸 게이지, 한도 근처 경고색), 조회·전송 중 상태(앰버 스캔·빠른 파형), 예정 행사 여부(앰버 셀), 본문 스크롤 위치(오른쪽 눈금자 표식). 나머지 셀 배치와 순번은 장식이며 수치를 나타내지 않습니다.
- 배치: 홈(12×2 레지스터, 초 스캔 줄, 행사 코드 바코드, 창 브래킷), 이벤트 목록(행 상태 램프, 6×4 베이), 행사 상세(무대 창 브래킷, 8×2 노드, 행사 코드), 아티스트(셀 스캔 줄과 스텐실 밴드 점멸, 명부 눈금자), 프로필(신원 카드 셀·바코드·브래킷), 방문자 로그(길이 게이지, 로그 창 브래킷), 소식 신청(오실로스코프, 8×4 번호 매트릭스), 소개(24×2 셀과 눈금자), 게스트 신청(조회 중 빨라지는 스캔선과 인장 셀).

## 상호작용과 모션

- 선택·호버는 행 전체를 녹색(예정은 앰버)으로 반전합니다. 켜짐은 즉시, 꺼짐은 180ms에 걸쳐 감쇠해 인광 잔상처럼 보입니다.
- 버튼은 1px 틀과 `→` 표식을 쓰고, 주 행동만 단색 블록입니다. 체크박스는 1px 틀 안의 사각 점으로 표시합니다.
- 섹션 표제·대표 행사명·프로필 이름·소개 문구는 글리프 노이즈에서 왼쪽부터 해독되며 나타납니다(첫 프레임은 페인트 전에 설정). 목록 행과 아티스트 셀은 순서대로 래스터 등장합니다.
- 첫 방문의 전원 켜짐은 탭 세션당 한 번 부팅 로그 네 줄을 출력한 뒤 약 950ms에 걸쳐 주사 단위로 물러납니다. route 전환은 본문에 260ms `steps(12)` 래스터 와이프와 선두 주사선을 줍니다.
- 화면 질감은 할레이션(모든 글자의 약한 번짐), 주사선, 가장자리 비네트, 9초 주기 롤링 밴드, 움직이는 입자 노이즈, 불규칙한 미세 플리커입니다.
- 별도 효과 스위치는 두지 않고, `prefers-reduced-motion`, 고대비, 데이터 절약, 숨겨진 탭에서 모션을 끕니다.

## 접근성

- 페이지 제목은 접근성 h1으로 유지합니다. 주요 조작 최소 높이는 44px(정밀 포인터의 상단 탭·시스템 칸은 34px)입니다.
- 포커스는 사각 아웃라인 대신 테두리 강조·반전·밑선으로 표시하고, 고대비에서는 시스템 색 선을 사용합니다.
- 상태 표시줄의 조회·전송 표시는 실제 query·요청 상태에 연결하며, 장식 요소는 접근성 트리에서 제외합니다.
