# TERMINAL 디자인 시스템

선명한 인광 녹색과 녹색 기가 도는 검정 바탕, 인쇄물 같은 좌우 rail과 가는 구획선으로 행사·사람·기록을 정리합니다.

- 바탕 `#010502`, 표면 `#050f08`, 주요 색 `#75e69a`, 본문 `#cbefd6`, 보조 텍스트 `#70ae85`, 구획선 `#367a4d`. 예정·진행 상태와 장식 노드에는 앰버 `#e8b96b`를 사용합니다.
- Space Mono는 정보·숫자·반전 패널 표제, Syncopate Regular는 행사·소개 표제, Syncopate Bold는 브랜드, Orbit은 한국어를 담당합니다. 로컬 font 자산을 사용합니다.
- 본문 14px, 긴 소개 13px, 폼·모바일 입력 16px, 데스크톱 CMD 입력 13px, 콘솔 로그 11px, 메타 9~12px. 주요 control 최소 44px, 숫자는 필요한 곳에 tabular.
- 홈은 요약/대표 행사/명령어 터미널, 이벤트는 2열 카드 목록/현황과 별도 상세, 아티스트는 명부 셀, 프로필은 신상/출연/소개, 방명록은 작성/공개 글의 고유 구성을 가집니다.
- 페이지당 행사 4개, 아티스트 12개, 공개 글 5개로 정보량을 제한합니다. 긴 원문은 native details로 열 수 있습니다. 동의·오류·주 행동은 생략하지 않습니다.
- 작은 화면은 의미 순서로 재배치하고 고정 헤더·푸터 사이의 본문 스크롤을 허용합니다. 화면 높이에 맞추기 위해 글자를 축소하거나 내용 전체를 숨기지 않습니다.
- 포커스에 사각 아웃라인을 사용하지 않습니다. 버튼·링크·펼치기는 2px 밑선, 입력은 라벨과 안쪽 밑선, 동의 체크박스는 연결된 문구의 밑선으로 선택 위치를 표시합니다. 터미널 입력은 앰버 CMD 표식·실선·안쪽 밑선으로, 본문과 로그 스크롤 영역은 상단 선으로 구별합니다. 표시는 포커스가 유지되는 동안 지속하며 고대비에서도 밑선·시스템 색 선을 유지합니다. selected와 hover, pending, empty, error, saved를 구별하고 reduced-motion 규칙을 유지합니다.
- 양쪽 직각 막대·빈 직사각 셀·8열 블록 매트릭스는 장식으로만 사용하며 접근성 트리에서 제외합니다. 가짜 수치·측정값·상태는 추가하지 않습니다. 경고색은 실제 실패 상태에만 씁니다.

패널 표제와 행사·아티스트 식별표는 녹색 반전 띠로 묶고, 보조 코드는 어두운 작은 칸으로 분리합니다. 카운트다운은 실제 시간의 네 단위를 각각의 숫자 창에 표시합니다. 카운트다운과 콘솔은 얇은 이중 프레임을 사용하며 원래의 정보 순서·녹색 팔레트를 유지합니다.

공통 프레임에는 40px 세로 rail과 반원형 절취 표식, 세로 인쇄 라벨을 사용합니다. 정적 주사선·색상 mask·가장자리 음영·낮은 강도의 인광 표현을 더하며 입력 글자는 선명하게 유지합니다. 하단 바코드와 기하 표식은 장식이며 데이터·입장권·보안 등급을 표현하지 않습니다. 방문자 글은 얇은 외곽선의 콘솔 구획에 표시합니다.

페이지 제목은 접근성 h1으로 유지하고, 큰 화면에서는 브랜드·주 메뉴·언어를 한 줄에 배치합니다. 행사 상세의 중앙은 실제 무대별 공연표 셀로, 아티스트 상세는 출연 날짜를 잇는 연대기로 구성합니다. 명부는 이름·출신과 직각 셀 표식, 이벤트 카드는 공개 출연진을 담는 매트릭스를 사용합니다. 진행 중·예정 행사는 앰버 상태 표식과 짧은 테두리 잔광으로 구별하고, 지난 행사는 정적인 인광 녹색으로 표시합니다. 신청서는 최대 650px의 이중 프레임과 정적 기하 인장으로 구별하고, 방문자 로그의 큰 숫자는 실제 메시지 글자 수를 나타냅니다. 상태 문구의 색은 고정하고 작은 표시등만 0.6~1초 주기로 즉시 켜졌다가 짧게 감쇠합니다. 카드 잔광은 별도 테두리 레이어의 투명도로 표시합니다. 실시간 숫자는 흐려졌다 나타나는 대신 120ms의 짧은 잔광으로 갱신을 알립니다. 정적인 소개·프로필 장식에는 반복 점멸을 넣지 않습니다. 페이지 장식에는 곡선·사선 회로·조준선·눈금·배경 격자를 사용하지 않으며, 매트릭스의 01–32는 데이터가 아닌 장식용 순번입니다. 본문 글자를 숨기거나 화면 전체를 점멸하지 않습니다. 하단 FX 버튼, `prefers-reduced-motion`, 고대비, 데이터 절약, 숨겨진 탭에서 효과를 중지합니다. 패널과 행은 겹쳐서 표시해 전체 표시 과정을 최대 약 310ms로 제한하며, 제어 상태 전환은 70ms입니다.


페이지의 장식 애니메이션은 해당 화면에서만 사용합니다. 홈 중앙의 양쪽 막대는 고정된 위치에서 교대로 점등합니다. 각 페이지에는 원본의 셀·스캔·인쇄식 프레임을 배정하며, 확대·축소하는 추상 도형이나 장식용 가짜 출력은 넣지 않습니다. 반복 장식을 배포하는 공통 컴포넌트 대신 화면별 형태와 움직임을 각 영역에서 소유합니다.

| 화면 | 전용 장식 |
| --- | --- |
| 홈 | 양쪽 막대의 교대 점등, 명령 출력 중 빠른 반응, 분절된 실제 상태 막대와 점등 스트립 |
| 이벤트 목록 | 6열 빈 직사각 셀의 부분 점멸 |
| 행사 상세 | 점선 프레임 안의 8×2 미리보기 노드 |
| 아티스트 목록 | 고정된 예정 출연 셀 테두리, 하단 표시등의 짧은 점등과 명부 끝선 |
| 아티스트 프로필 | 실제 출신 표기와 인쇄식 프레임·표시등 |
| 소개 | 이중 구획선·플랫폼 인쇄 패널과 2×2 키워드 모듈 |
| 소식 신청 | 8×4 번호 매트릭스 중 전송 상태 셀의 짧은 점등 |
| 게스트 신청 | 직각 인장을 지나는 수직 스캔선 |
| 방문자 로그 | 실제 로그 콘솔과 줄무늬·표시등으로 나뉜 하단 패널 |

홈 우측 콘솔은 1px 외곽선, 상단·좌우 10px와 하단 4px 여백, 2px 주사선, 아래에 쌓이는 로그와 점선 CMD 입력줄을 사용합니다. 터미널의 크기 계산을 내부 기록과 분리해 명령이 쌓여도 패널이나 페이지 높이가 늘어나지 않게 합니다. 출력 영역은 입력줄을 제외한 내부 높이를 모두 채우고, 긴 기록은 그 안에서만 스크롤합니다. 접근성용 숨김 텍스트의 배치 기준도 터미널 내부로 제한합니다. 출력에 별도의 최대 높이를 두지 않아 위쪽에 빈 공간이 생기지 않으며, 짧은 기록만 아래에 정렬합니다. 첫 화면에 실제 명령어 목록을 표시하고, 입력이 비어 있으면 8×13px 블록 커서를 점멸합니다. 새 응답은 글자 단위로 빠르게 표시하며 줄바꿈에서 짧게 멈춥니다. 긴 응답은 여러 글자를 묶어 표시하고 약 1.2초 후 남은 내용을 펼쳐 다음 명령을 오래 기다리지 않게 합니다. 입력줄은 24px 한 줄 높이를 유지하고, 출력 중에도 명령을 입력하거나 Esc로 전체 응답을 펼칠 수 있습니다. 긴 출력은 내부 스크롤하며 이전 기록을 읽는 동안에는 자동 스크롤을 멈춥니다. [ENTER] 실행 버튼·IME·history·완성된 응답의 스크린리더 로그를 유지합니다.

공개 로그 하단의 세 표식은 최초 조회·페이지 조회·갱신·재시도 중에만 앰버로 점멸하고, 응답 후 인광 녹색으로 정착하며 실패하면 경고색으로 멈춥니다. 기록 전송 중에는 작성 패널의 분절선이 반응합니다. Signal 매트릭스는 저장 중 점등·완료 후 고정·실패 시 경고색을 표시하고, Access 스캔은 행사 조회·코드 확인·신청 저장 중에 작동합니다.

아티스트의 참여 횟수·최근 출연 요약과 집계 표식은 사용하지 않습니다. 콘솔의 각 명령과 텍스트 응답은 스크롤 기록에 누적되고, 같은 탭에서 화면을 오가거나 새로고침해도 복원됩니다. 장식은 부족한 패널의 밀도를 보완하되 가짜 데이터·곡선 그래픽을 추가하거나 동일 애니메이션을 다른 페이지에 반복하지 않습니다.
