# TERMINAL 디자인 시스템

테크노 이벤트를 위한 힙노틱·퓨처리스틱 콘솔입니다. 짙은 남색 작업면에 남색 판을 맞물리고, 크림·골드·오렌지·레드 단색 판을 소수만 두어 대비를 크게 만듭니다. 판 안은 실제 데이터를 쪼갠 셀과 표로 빽빽하게 채우고, 동심원 링을 하나의 그래픽 모티프로 씁니다. 우주선 장비 UI는 구조 참고일 뿐이며 깎인 모서리·⊗ 표식·사선 해칭 같은 게임 UI 기호는 쓰지 않습니다. 터미널 은유, CRT 효과, 하드웨어 베젤, 슬로건 문구도 쓰지 않습니다.

## 색

- 팔레트: 크림 `#fce5cd`, 골드 `#fcbf49`, 오렌지 `#f77f00`, 레드 `#d62828`, 남색 `#003049`. 작업면 `#001a29`, 헤더·푸터 바 `#00121d`.
- 남색 판: 크림 글자(11.3:1), 흐린 글자 `#c9b8a6`, 표제·숫자는 골드(8.4:1), 셀은 크림 바탕에 남색 글자. 크림·골드 판: 남색 글자와 남색 셀. 오렌지 판: `#001a29` 글자(6.8:1). 레드 판: `#fff8f0` 글자(4.75:1)와 남색 셀. 레드는 남색 위 글자로 쓰지 않습니다.
- 상태: 예정은 골드 셀, 진행 중은 레드 판, 대표 행사는 오렌지 판, STANN LUMO는 오렌지 셀, 지난 기록은 크림.
- `data-surface="navy|deep|cream|gold|orange|red"`가 판 색과 역할 토큰(`--ink`, `--muted`, `--accent`, `--line`, `--fill`, `--on-fill`)을 정합니다.

## 글꼴과 크기

- "TERMINAL"이라는 단어는 어디서든 `ProcrastinatingPixie`(`public/fonts`)로 씁니다(`BrandText`). 헤더 로고는 2026-03-07 로고를 트레이스한 워드마크 SVG입니다.
- 표제·라벨·버튼은 `Barlow Condensed` 600–800 대문자, 본문은 `Barlow`, 숫자·코드는 `Share Tech Mono`(OFL, Latin woff2). 한글은 시스템 산세리프입니다.
- 크기는 1280→1920px에 따라 커지는 7단계입니다: `--t-xs` 12–14px(칩·메타) · `--t-sm` 14–16 · `--t-md` 16–18(본문·값) · `--t-lg` 19–24(셀 이름·버튼) · `--t-xl` 26–38(판 표제·행 제목) · `--t-2xl` 36–60(카운터·큰 숫자) · `--t-3xl` 56–124(대표 세션명). 12px 미만 글자는 쓰지 않습니다. 여백 `--pad`와 간격 `--gap`도 화면 폭에 따라 커집니다.

## 화면 구조

- 셸: 짙은 헤더 바(골드 워드마크 · `01 HOME` 탭 · 조회 램프 · KST 시계 · KO/EN · 오렌지 링 블록, 오렌지 하단선), 판이 타일링되는 작업면, 레드 상단선의 푸터 바.
- 판: 직각 판, 골드 영문 표제와 3px 표제선, 한글 제목, 오른쪽 칩. 안에는 소제목, 크림 라벨 칸/선 값 칸, 셀 격자, 칩, 분할 막대를 층층이 둡니다. 남는 높이는 가는 선과 짧은 이름만 둔 예비 칸(`Bay`)으로 비워 둡니다. 로고 모양 장식(열린 사각 프레임)은 쓰지 않습니다.
- 버튼은 화살표 없이, 판 아래(또는 판 바닥)에 붙는 별도 카드 `ActionDeck`(짙은 바탕, 오렌지 왼쪽 선, 세로 라벨)에 모읍니다.
- 동심원 링은 대표 행사 판과 헤더·푸터의 링 블록에만 쓰며, 모두 같은 박자(128 BPM, 1.875초에 한 링)로 퍼집니다.
- 홈: NEXT SESSION 오렌지 판(뒤에서 링이 퍼지는 힙노틱 필드, 카운트다운, 일정, 라인업) / SESSION ARCHIVE / STATUS 골드 판 / ARTIST ROSTER / NODE ACTIVITY(시각 · NODE-XXXX만, 닉네임·메시지 없음) / SIGNAL 레드 판.
- 목록은 칸 행과 크림·골드 ID 셀, 상세는 SESSION(상태 색) · RUNNING ORDER · BRIEFING · ACCESS 판, 아티스트는 셀 격자와 집계 판입니다.

## 상호작용과 모션

- 호버는 카드 전체가 반응합니다. 행은 모든 칸이 골드로 켜지며 옆으로 밀리고, 셀은 위로 떠오르며 골드 밑선이 생깁니다(140ms). 제목만 링크인 카드도 링크 영역을 카드 전체로 넓힙니다.
- 모션: 페이지를 열 때 판이 차례로 떠오릅니다. 링은 박자에 맞춰 퍼지고, 푸터에는 실제 일정 데이터가 흐르는 티커가 있습니다(호버 시 멈춤). 조회·전송 중에는 램프가 깜빡입니다. 부팅·스캔·타자 출력은 없습니다.
- `prefers-reduced-motion`, 고대비, 데이터 절약, 숨겨진 탭에서 모션을 끕니다.

## 접근성

- 페이지 제목은 접근성 h1입니다. 영문 판 표제·코드·일련번호·예비 칸은 `aria-hidden`이라 heading과 링크 이름은 한글 제목과 실제 내용만 읽습니다.
- 주요 조작 최소 높이는 44px입니다. 포커스는 남색 위에서 골드, 밝은 판 위에서 짙은 색 2px 아웃라인이며, 채운 요소는 안쪽 아웃라인을 씁니다. 고대비에서는 시스템 색을 씁니다.
