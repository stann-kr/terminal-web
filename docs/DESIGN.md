# TERMINAL 디자인 시스템

낮은 채도의 아이스블루와 청회색 바탕, 인쇄물 같은 좌우 rail과 가는 구획선으로 행사·사람·기록을 정리합니다.

- 바탕 `#010304`, 표면 `#050c10`, 주요 색 `#54acd2`, 본문 `#b5d8e3`, 보조 텍스트 `#699bb0`, 구획선 `#34647a`. 예정·진행 상태와 장식 노드에는 앰버 `#e8b96b`를 사용합니다.
- Space Mono는 정보·숫자, Syncopate Regular는 가는 패널 표제, Syncopate Bold는 브랜드, Orbit은 한국어를 담당합니다. 로컬 font 자산을 사용합니다.
- 본문 14px, 긴 소개 13px, 폼·모바일 입력 16px, 데스크톱 CMD 입력 13px, 콘솔 로그 11px, 메타 9~12px. 주요 control 최소 44px, 숫자는 필요한 곳에 tabular.
- 홈은 요약/대표 행사/명령어 터미널, 이벤트는 2열 카드 목록/현황과 별도 상세, 아티스트는 명부 셀, 프로필은 신상/출연/소개, 방명록은 작성/공개 글의 고유 구성을 가집니다.
- 페이지당 행사 4개, 아티스트 12개, 공개 글 5개로 정보량을 제한합니다. 긴 원문은 native details로 열 수 있습니다. 동의·오류·주 행동은 생략하지 않습니다.
- 작은 화면은 의미 순서로 재배치하고 고정 헤더·푸터 사이의 본문 스크롤을 허용합니다. 화면 높이에 맞추기 위해 글자를 축소하거나 내용 전체를 숨기지 않습니다.
- 포커스는 2px 아이스블루 외곽선. selected와 hover, pending, empty, error, saved를 구별합니다. reduced-motion 규칙을 유지합니다.
- 수평 점선 위의 사각 커서·빈 직사각 셀·8열 블록 매트릭스는 장식으로만 사용하며 접근성 트리에서 제외합니다. 가짜 수치·측정값·상태는 추가하지 않습니다. 경고색은 실제 실패 상태에만 씁니다.

공통 프레임에는 40px 세로 rail과 반원형 절취 표식, 세로 인쇄 라벨을 사용합니다. 정적 주사선·색상 mask·가장자리 음영·낮은 강도의 인광 표현을 더하며 입력 글자는 선명하게 유지합니다. 하단 바코드와 기하 표식은 장식이며 데이터·입장권·보안 등급을 표현하지 않습니다. 방문자 글은 얇은 외곽선의 콘솔 구획에 표시합니다.

페이지 제목은 접근성 h1으로 유지하고, 큰 화면에서는 브랜드·주 메뉴·언어를 한 줄에 배치합니다. 행사 상세의 중앙은 실제 무대별 공연표 셀로, 아티스트 상세는 출연 날짜를 잇는 연대기로 구성합니다. 명부는 작은 셀과 실제 출연 연도 표식, 이벤트 카드는 공개 출연진을 담는 매트릭스를 사용합니다. 진행 중·예정 행사는 앰버 상태 표식과 느린 테두리 맥동으로 구별하고, 지난 행사는 정적인 청색으로 표시합니다. 신청서는 최대 650px의 이중 프레임과 정적 기하 인장으로 구별하고, 방문자 로그의 큰 숫자는 실제 메시지 글자 수를 나타냅니다. 텍스트 색 전환과 도형 점멸은 2.4~3.6초, 카드 테두리 맥동은 2초 주기를 사용합니다. 사각 커서는 5초마다 수평 트랙을 이동합니다. 페이지 장식에는 곡선·사선 회로·조준선·눈금·배경 격자를 사용하지 않으며, 매트릭스의 01–32는 데이터가 아닌 장식용 순번입니다. 본문 글자를 숨기거나 화면 전체를 점멸하지 않습니다. 하단 FX 버튼, `prefers-reduced-motion`, 고대비, 숨겨진 탭에서 효과를 중지합니다.


페이지의 장식 애니메이션은 해당 화면에서만 사용합니다. 홈의 수평 이동 표식은 한 번만 사용합니다. 각 페이지에는 원본의 셀·스캔·인쇄식 프레임을 배정하며, 확대·축소하는 추상 도형이나 장식용 가짜 출력은 넣지 않습니다. 반복 장식을 배포하는 공통 컴포넌트 대신 화면별 형태와 움직임을 각 영역에서 소유합니다.

| 화면 | 전용 장식 |
| --- | --- |
| 홈 | 수평 점선의 사각 커서 |
| 이벤트 목록 | 6열 빈 직사각 셀의 부분 점멸 |
| 행사 상세 | 점선 프레임 안의 8×2 미리보기 노드 |
| 아티스트 목록 | 예정 출연 셀의 테두리 점멸, 정적 명부 끝선 |
| 아티스트 프로필 | 실제 출연 수와 연도 범위의 인쇄식 표식 |
| 소개 | 이중 구획선과 플랫폼 이름의 인쇄 패널 |
| 소식 신청 | 8×4 번호 매트릭스의 색 전환 |
| 게스트 신청 | 직각 인장을 지나는 수직 스캔선 |
| 방문자 로그 | 실제 로그 콘솔과 정적 이중 끝선 |

홈 우측 콘솔은 1px 외곽선, 10px 안쪽 여백, 2px 주사선, 아래에 쌓이는 로그와 점선 CMD 입력줄을 사용합니다. 첫 화면에 실제 명령어 목록을 표시하고, 입력이 비어 있으면 8×13px 블록 커서를 점멸합니다. 긴 출력은 내부 스크롤하며, [ENTER] 실행 버튼·IME·history·스크린리더 로그를 유지합니다.
